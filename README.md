# Currency Converter

A simple currency converter that converts USD to IRR and IRR to USD.

**Live:** https://rira-task-seven.vercel.app/

## Features

- Convert between USD and IRR with a custom rate
- Swap the conversion direction
- Input validation and thousands separators
- History of previous conversions

## Tech Stack

React, TypeScript, Vite, Tailwind CSS, React Hook Form, Zod

## Run Locally

```bash
npm install
npm run dev
```
